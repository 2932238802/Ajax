# Ajax

一个使用 Rust 编写的**终端文字生存游戏**。在字符构成的世界中探索、管理自身状态，并通过文本指令与游戏交互。

## 特性

- **手写 ECS 架构**：基于 `Entity` / `Component` / `World` / `Storage` 的轻量级实现，组件与实体解耦。
- **随机地图生成**：每次新游戏随机生成地形分布（家、森林、平原、山地、河流、沼泽、沙漠、洞穴、海滩、湖泊等）。
- **彩色终端渲染**：地图与界面支持彩色显示。
- **游戏时间系统**：游戏内时间随现实时间流逝，支持耗时动作的时间推进。
- **玩家状态系统**：健康、精神、饥饿三项状态属性，并随时间变化。
- **文本指令交互**：通过指令完成查看状态、查看地图、查看时间、保存等操作。
- **存档 / 读档**：游戏进度序列化为 JSON 存档，支持下次继续。

## 快速开始

### 环境要求

- [Rust](https://www.rust-lang.org/) 工具链（包含 `cargo`）

### 运行

```bash
cargo run
```

### 构建

```bash
cargo build
```

## 玩法说明

### 主菜单

启动后进入主菜单，可进行以下操作：

| 选项 | 说明 |
|------|------|
| 1. 开始游戏 | 创建新的游戏世界 |
| 2. 继续游戏 | 读取已有存档（无存档时不可用） |
| 5. 退出游戏 | 退出程序 |

### 指令列表

| 指令 | 别名 | 说明 |
|------|------|------|
| `exit` | `quit` / `q` | 保存并退出游戏 |
| `help` | `h` | 显示帮助信息 |
| `save` | - | 保存游戏进度 |
| `status` | `s` | 查看全部状态（健康 / 饥饿 / 精神） |
| `status h` | - | 仅查看健康状态 |
| `status u` | - | 仅查看饥饿状态 |
| `status m` | - | 仅查看精神状态 |
| `time` | `t` | 查看当前游戏时间 |
| `map` | `m` | 显示地图 |

### 存档位置

存档文件保存于用户主目录下的隐藏文件夹：

```
~/.ajax/.user_data.json
```

（Windows 上对应 `C:\Users\<用户名>\.ajax\.user_data.json`）

## 项目结构

```
src/
├── main.rs              程序入口
├── core/                核心逻辑
│   ├── game.rs          游戏主循环与状态机
│   ├── map.rs           地图生成与渲染
│   ├── terrain.rs       地形枚举
│   ├── time.rs          游戏时间系统
│   ├── data.rs          存档数据结构
│   ├── event.rs         事件枚举
│   ├── register.rs      更新函数注册器
│   └── world/           ECS：实体 / 世界 / 存储
├── component/           组件：健康 / 饥饿 / 精神 / 位置
├── entity/              实体：玩家
├── command/             指令系统：解析 / 路由 / 执行
├── constants/           常量定义
└── system/              系统层（预留）
```
